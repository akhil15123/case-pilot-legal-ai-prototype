# Project Summary

## Name

CasePilot: Plaintiff Case Intelligence Prototype

## Type

Recent personal project prototype, March 2026

## One-line description

Built a full-stack plaintiff-side legal AI prototype that analyzes multiple case files, generates chronologies, scores evidence coverage, flags missing support, models damages, and drafts exportable attorney work product with citations.

## What it does

- processes intake, police, medical, therapy, MRI, and billing records
- supports multiple plaintiff matters through a reusable case workspace
- creates a date-sorted chronology with source references
- produces an executive strategy memo and evidence coverage matrix
- identifies contradictions, treatment gaps, and missing support
- estimates current specials from billing
- models future-care reserve and wage loss when supported
- drafts a plaintiff-side demand summary
- answers case questions from the record set

## Why it matters

This project mirrors the practical work done by legal AI tools for plaintiff firms: shortening review time, structuring messy records, and turning them into reliable attorney work product.

## Technical highlights

- full-stack local demo with clean API boundaries
- deterministic reasoning pipeline for explainability
- issue-spotting logic tied to litigation workflows
- frontend designed as a legal review workspace, not generic document chat
- downloadable memo export and searchable source library
